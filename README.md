## Engineering Mindset
* **Root Cause Analysis:** 현상 수정보다 문제의 근본 원인을 파악하여 재발 방지에 집중합니다.
* **Scalability:** 현재의 기능 구현을 넘어, 서비스 확장 시 발생할 병목 현상을 미리 고민합니다.
* **User-Centric:** 개발 편의성보다 실제 사용자가 겪을 경험과 비즈니스 가치를 우선합니다.
